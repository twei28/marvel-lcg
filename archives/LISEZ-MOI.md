# archives/ : les zips et fichiers en vrac de la racine (rangés le 04/11/2026)

Rien ici n'est dans git (tout est ignoré) et rien n'est sauvegardé sur le serveur : les zips se retéléchargent depuis Google Drive.

- `zips-a-faire/` : héros pas encore montés ou en cours (Multiple Man, Punisher, 3-D Man, Silver Surfer). Déplacer vers `zips-deja-importes/` une fois le pack commité.
- `zips-deja-importes/` : héros et campagnes dont le pack est monté dans `Fusion/marvel-lcg-src/src/cards/pack/`.
- `zips-a-verifier/` : contenus mélangés (Kajislav en 4 parties, Alt Art, Resource Cards, PREVIEWS) : à trier quand on voudra.
- `outils-et-kits/` : kits IA, polices des gabarits, cardmaker.
- `divers/` : vidéos et captures sans nom.

Le travail sur un héros se fait dans `A créer/import-<héros>/` (zip extrait, notes de lecture, prompt de reprise), pas ici.
