## Socle commun a tout le lot (a lire une fois)

- Le « corruption counter » est un compteur NOMME. Le type `CardFace.COUNTER` (`Fusion/marvel-lcg-src/src/game/card/face/card_face.py:277`) ne contient PAS `'corruption'` (verifie : liste lue en entier, derniers ajouts `drone`, `wanted`, `acceleration`, `intelligence`). A ajouter avant tout script (meme geste que `'wound'` l.338, `'chi'`, `'ratings'`).
- OVERPOWERING n'est PAS dans `CardFace.TRAITS` (grep sur `game/` : zero resultat). A ajouter. DEMON, HAND, NINJA, UNDEAD, BRUTE, SPELL, MYSTIC existent deja (lus dans la meme liste).
- Poser/retirer un compteur sur une autre carte : `Faces.PlaceCountersOn(cibles, n, 'nom', effect, maximum=...)` (`game/operate/faces.py:213`), `Faces.RemoveCountersOn` (l.227). Cout « placez un compteur sur X » : `CostFunc.PlaceCounter(cible, n, 'nom')` (`game/ability/cost_func.py:984`, utilise par `Fusion/marvel-lcg-src/src/cards/pack/gambit/gambit/37008.py` : `CostFunc.PlaceCounter(CardFinder(name="Gambit"), 1, 'charge')`). Compter : `face.GetCounters('nom')`.
- Modele d'assistant « poser des compteurs sur l'amelioration unique d'un joueur » : `PlacerCompteursFlecheSurArc(effect, n)` dans `Fusion/marvel-lcg-src/src/cards/pack/kate_bishop/kate_bishop/__init__.py:30` (cherche la carte en jeu puis `Faces.PlaceCountersOn`). Les cartes sl devront partager UN assistant du meme genre (« la Creeping Corruption DU JOUEUR X », pas « une Creeping Corruption »).
- Piege commun a toutes les cartes du lot : il y a UNE Creeping Corruption PAR JOUEUR. `CardFinder(name="Creeping Corruption")` (comme `CardFinder(name="Gambit")` de 37008, qui est unique) peut viser la copie d'un AUTRE joueur en multijoueur : restreindre au joueur qui joue/revele/est attaque. Invisible en solo : un cas `heros2` est obligatoire (RECETTES-MOTEUR §15, `"YouControlUnit"` exclut les autres joueurs).
- Lire un trait sur la face COURANTE d'une carte : `face.HasTrait("X")` (`game/card/face/model/trait.py:53`) ; exemple d'usage dans `Fusion/marvel-lcg-src/src/cards/pack/sm/down_to_earth/27133.py` (`alter_ego.HasTrait("CIVILIAN")`).
