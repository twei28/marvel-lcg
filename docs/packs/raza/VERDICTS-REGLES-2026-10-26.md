# Verdicts raza

Q1. rl001a/b Alien Augmentations (Fusion/marvel-lcg-src/assets/pics/rl001a.jpg) — « +1 hit point for each unattached TECH or WEAPON upgrade you control » : B : LE CODE DOIT CHANGER (et le gabarit part d'une erreur). RR Upgrade : « Most upgrade cards enter play near a player's identity card… Some upgrades enter play and “attach to” another card. » Une amélioration ordinaire n'est donc PAS attachée : « unattached » = toutes sauf celles posées sur une autre carte par « Attach to » (sur un allié, un sbire…). Raza garde son bonus pour Blaster, Sabre, Eye, Arm, Tools ; il faut seulement exclure les améliorations attachées à une autre carte.
Q2. rl002 Tolo Hawk (Fusion/marvel-lcg-src/assets/pics/rl002.jpg) — « Interrupt: When Tolo Hawk would be defeated by consequential damage, instead… » : A CONFIRMÉ (facultative) : imprimé « Interrupt », pas « Forced Interrupt » (RR Forced Interrupt n'existe que si le mot Forced est écrit).
Q3. rl003 / rl004 (Fusion/marvel-lcg-src/assets/pics/rl003.jpg, Fusion/marvel-lcg-src/assets/pics/rl004.jpg) — « for each WEAPON / TECH you control » : A CONFIRMÉ : aucun type de carte n'est précisé, toute carte que vous contrôlez qui porte le trait compte.
Q4. rl005 Warrior Apotheosis (Fusion/marvel-lcg-src/assets/pics/rl005.jpg) — « each enemy that attacked you this way » : A CONFIRMÉ. RR Stun : « If a stunned villain or minion would attack, discard the stunned status card instead… that character is not considered to have attacked. »
Q5. rl007 Warrior Pride (Fusion/marvel-lcg-src/assets/pics/rl007.jpg) — « draw 1 card. If you have sustained 5 or more damage, heal 1 » : A CONFIRMÉ : les phrases se résolvent dans l'ordre imprimé ; piocher ne change de toute façon pas les dégâts subis.
Q6. rl008 Raza's Cybernetic Arm (Fusion/marvel-lcg-src/assets/pics/rl008.jpg) — « (Retaliate will trigger for attacks that cause Raza to gain Retaliate) » : la parenthèse N'EST PAS ambiguë : une attaque qui fait passer Raza à 5 dégâts ou plus déclenche la riposte (RR Retaliate : « Forced Response: After this character is attacked », vérifiée APRÈS l'attaque). B : LE CODE DOIT CHANGER si le moteur ne le fait pas : le contre-cas actuel (tools/cas/raza.py, « sous 5 degats (4) aucune riposte », Rhino attaque et doit amener Raza à 5+) attend 0 riposte, soit le contraire de la parenthèse. À vérifier : si l'attaque de Rhino est bien non défendue dans ce cas, le cas est faux.
Q7. rl012 Honour-Bound Warrior (Fusion/marvel-lcg-src/assets/pics/rl012.jpg) — « each of your upgrades » : A CONFIRMÉ. RR Obligation : « you / your apply only to the player whose play area the obligation is in ».
Q8. rl013 Zzzxx (Fusion/marvel-lcg-src/assets/pics/rl013.jpg) — « gains Villainous for that activation » / « Boost: boost icons equal to the villain's stage number » : A CONFIRMÉ. B contredit le texte imprimé (Boost = numéro de stade).
Q9. rl014 Symbiote Possession (Fusion/marvel-lcg-src/assets/pics/rl014.jpg) — « Players engaged with Zzzxx cannot attack Zzzxx or thwart schemes other than this one » : A CONFIRMÉ : l'interdiction vise le JOUEUR (RR Player : sa zone comprend ses alliés), pas seulement son identité ; sinon un allié contournerait la manigance.
Q10. rl015 Shi'ar Host (Fusion/marvel-lcg-src/assets/pics/rl015.jpg) — « an attachment that can be attached to Shi'Ar Host » : A CONFIRMÉ, au sens du RR Attach To : « The “attach to” phrase is checked for legality when the card would be attached » → tout attachement dont le « Attach to » accepte ce sbire (a minion, a character, an enemy, the minion with…). C exclu.
Q11. rl016 New Host (Fusion/marvel-lcg-src/assets/pics/rl016.jpg) — DOUTE RÉEL. Règle stricte (RR Attach To : « If the initial “attach to” check does not pass, the card is not able to be attached… If such a card cannot remain in its prior state or game area, discard it ») : un sbire dans la défausse n'est pas en jeu → New Host serait défaussé, sans effet, et sa Réponse forcée ne servirait jamais. La carte officielle copiée (Cruel Experiment 45124) dit explicitement « Reveal that minion and attach » ; New Host a perdu le « Reveal ».
  Question : « New Host dit : “Discard cards from the top of the encounter deck until you discard a minion. Attach New Host to it.” Le sbire défaussé n'est pas en jeu. Que fait-on ? »
  Options : 1) On révèle ce sbire (il entre en jeu engagé avec vous) puis New Host s'y attache, comme Cruel Experiment (recommandé, déjà codé) ; 2) Règle stricte : le sbire reste dans la défausse, New Host est défaussé sans effet.
Q12. rl017 Devour (Fusion/marvel-lcg-src/assets/pics/rl017.jpg) — « Discard an ally you control » : A CONFIRMÉ en solo (le joueur choisit). En multijoueur, la règle stricte donne le choix au premier joueur (RR First Player, « multiple eligible targets, the first player selects ») : même écart que sq014, mineur.
Q13. rl018-rl020 Energy / Genius / Strength (Fusion/marvel-lcg-src/assets/pics/rl018.jpg) — B : LE CODE DOIT CHANGER. Même titre que les ressources officielles 01088-01090 et « Max 1 per deck » imprimé ; RR Unique/Copies : « A copy of a card is defined by title. » → ce sont des copies de Energy/Genius/Strength : la limite 1 est COMMUNE (au mieux des arts alternatifs). Cartes à part avec 1 max chacune permettent 2 Energy, interdit. (Même vérif à faire pour le précédent Hellcat / Corsair, hors de mon périmètre.)
