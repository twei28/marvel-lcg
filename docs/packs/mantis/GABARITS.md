## Decisions de montage (a lire avant de toucher aux cartes)

- **mt001a Empathetic Advantage** (la carte difficile). Une identite ne porte QU'UNE `CanGenerateResources` (`identity.py:19`, assert) et le montant genere est FIGE a l'annonce du paiement, avant le choix de la carte a defausser. Solution retenue (01/11/2026, reponse « pas d'ecart ») : **DEUX moyens de paiement** sur l'identite, un par origine, le joueur choisit l'origine en choisissant le moyen : « Empathetic Advantage » (origine ENNEMI, `[wild][mental]`, la `CanGenerateResources` unique) et « Empathetic Advantage (character) » (origine personnage ami, `[mental]`, `AbilityFactory.CheckThisCanPayCost` ecrit a la main, `SetFuncName("CheckPay")`, avec son propre `DoGenerateResources` et un `bind_ability` par NOM). Chaque moyen n'est offert que s'il a une carte Desorientee a defausser. Plus aucun ecart de regle (le joueur peut viser son personnage meme si un ennemi est confus). La limite « once per round » est un compteur de round partage (`world.stat.AddRoundCounter`), pas `LimitOncePerRound` (que The Celestial Madonna ne peut pas relancer). **A voir a l'ecran** : l'identite expose deux entrees de paiement (pas encore vues dans l'interface, voir « Manques »).
- **mt010 The Celestial Madonna** : « Hero Interrupt : When you resolve ... exhaust → this use does not count ». Le message de paiement (`WhenPlayerPayingResources`) n'admet pas d'Interruption (categorie « Paying », assert de `RegisterEffect`) : la capacite part sur `AfterCardsBeSpendAsResource` (juste apres le paiement), incline Madonna et decremente le compteur. Meme effet de jeu, fenetre un peu plus tardive. **Non couvert** : la FAQ « deux emplois pour payer la MEME carte » (le moteur ne compte qu'une source par paiement).
- **Allies `2*`** : l'etoile apres le chiffre d'un allie = degats consecutifs (convention du depot) ; Drax a THW 2* et ATQ 2*.
- **mt002 Drax** : « [star] basic attack gains piercing and ignores the guard keyword » : `UnitAttackGainKeyword("This", piercing=True)` sans `is_basic_attack` (le filtre n'etait pas vrai sur le message d'attaque d'un allie ; Drax n'a aucune autre attaque) + `UnitIgnoreKeywordIcons(guard=True)` limite au pouvoir de base d'ATQ. Le bonus « add THW to ATK while confused » se relit a chaque changement d'etat (`OnEvent.Status`).
- **mt011 Psychic Tremor** : « Discard this obligation » appartient a la SECONDE branche (gabarit des obligations officielles `01165` / `03026`). Le nombre de cartes a defausser est borne par la main ; le surge est « donne » quand rien n'a ete defausse.
- **mt012 Death Blossom's Bloom** : `UnitCannotBeConfused(Enemy)` (buff) + retrait des statuts a la revelation (FAQ imprimee : ils sont enleves des l'entree en jeu). Menace initiale `2*` (par joueur), boost 3, Incite 1, lus sur l'image.
- **mt015 Cotati Resiliency** : `AttachToFaceWhenPutIntoPlay(CardFinder(Enemy, check_face_fn = pas Stoique), highest_printed_hp=True, if_cannot_gain_surge=True)` + `GiveKeywordToAttached(stalwart=1)`.
- **mt016 Mindlink** : « Spend up to 2 [mental] » = depense dans le corps de l'effet (`AskSpendResourcesInternal(Cost("BB", up_to=True))` : un `SetCost` sur la capacite de jeu empechait l'evenement d'etre jouable) ; Team-Up = `desc.TeamUp` + `SetTarget("TeamUp")`. Version EVENEMENT (image de l utilisateur) confirmee le 01/11/2026.
- **Pieges de mesure rencontres** : `Puzzle.Confuse` BASCULE ; un statut Desoriente disparait quand le personnage THWART (Precognition retire donc la confusion de Mantis) ; Drax ne peut pas attaquer un sbire (ne pas le tester sur Sandman) ; `Puzzle.PutIntoPlay` d'une carte deja en jeu ne cree pas de copie ; `set_name` vide = pas de module charge ; la fonction `get_new_value` de `GiveKeywordToInPlayWhenApplyThis` prend `(effect, face)` (pas `ui`) ; une `ForChoiceAbility` ne prend pas `SetNoTarget()` (elle disparaissait des choix) ; `preferer_option='Cancel'` pour refuser un « you may ».

1. **Aucune partie reelle humaine complete.** Autoplay seulement. Maintenant, tant que le cout est deja couvert, le toucher suivant passe au moyen alternatif QUI COUVRE AUSSI le cout, puis rend tout (4 tests `ressources-multiples.test.ts`, rouge avant / vert apres) ; rejoue a la souris (spec `mantis-avantage`, test C : Rhino garde son statut, Mantis perd le sien). Le moyen pose est maintenant DIT dans la fenetre de paiement (« Tout est pret · Mantis : mental + joker », `moyensChoisisDesAlternatives`, `interaction.ts`, 2 tests). Les libelles de choix de Mantis sont traduits (`vocabulaire-moteur.ts`, ex. « Empathetic Advantage : défausser une carte d’état Désorienté », « Soigner 1 dégât d’un personnage allié ») ; le nom de capacite imprime reste anglais comme sur le scan.
