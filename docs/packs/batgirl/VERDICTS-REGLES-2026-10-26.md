# Verdicts Batgirl (bg)
1. bg005 Batarangs (/home/oem/Desktop/Marvel LCG/Fusion/marvel-lcg-src/assets/pics/bg005.jpg) — « For each resource you used to pay for this event, if that resource is: [energy] Stun / [physical] 2 dmg / [mental] Confuse ». Codé : un wild ne compte pour aucune ligne.
   B : le code doit changer. RR « Wild Resource » : « When a player generates a wild resource, they may specify which resource type (energy, mental, physical, or wild) it is being used as. » Un wild dépensé pour payer Batarangs compte pour la ligne du type que le joueur déclare (la restriction « no characteristic other than wild » ne vaut que hors paiement d'un coût, ce qui n'est pas le cas ici).
2. bg006 Master Plan (/home/oem/Desktop/Marvel LCG/Fusion/marvel-lcg-src/assets/pics/bg006.jpg) — « Draw a card » est-il dans la 2e puce ? A confirmé : sur le scan, « Draw a card. » est imprimé dans le même paragraphe que la 2e puce (aucune ligne ni puce propre) ; RR « Event » : le joueur choisit UNE des capacités ; la pioche suit seulement l'option 2.
3. bg012 Utility Belt (/home/oem/Desktop/Marvel LCG/Fusion/marvel-lcg-src/assets/pics/bg012.jpg) — « Hero Action: When you would play an event, exhaust this card → reduce the cost of that event by 1. » Codé : réduction AUTOMATIQUE tant que la ceinture est prête + inclinaison forcée, sans contrôle de forme.
   B : le code doit changer. RR « Action » / « Triggered Abilities » : une Action est facultative (« Players are permitted to trigger… ») ; « If the bold timing trigger contains the word "Hero"… can only be used if the player is in hero form ». Le joueur doit pouvoir REFUSER (garder la ceinture prête pour le +1 main de la 2e capacité) et seulement en forme héros. Le texte imprimé prime sur l'ancien FAQ (pas de doute là-dessus).
