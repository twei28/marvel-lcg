# Mode multi-tables de Kingsfall (assemblees, « pods ») : decisions de l'utilisateur

Debut le 22/10/2026. Cartes : pu147 Long Live the King?, pu148 Power to the People, pu149a/b Long Live / Down With, pu151 The King. Livret FR p.10-11 (« Scenario multijoueur »).

| # | Question | Decision |
|---|---|---|
| 1 | Comment les groupes d'une assemblee se retrouvent | **Un code d'assemblee partage** : la 1re table qui lance Kingsfall epique cree l'assemblee et recoit un code court ; les autres entrent ce code en creant leur partie ; la 1re table est l'organisatrice (Longue vie et Le Roi vivent chez elle) |
| 2 | Une table ferme ou abandonne avant la fin | **Une defaite du groupe** : 1 menace par joueur du groupe sur Le Roi ; les autres tables ne restent pas bloquees, le resultat tombe des que toutes les parties sont finies ou fermees |
| 3 | Ou mettre Longue vie et Le Roi | **Chez tous, en miroir** : chaque table a les deux cartes en jeu et montre le meme total commun ; chacun peut faire l'Action d'assemblee depuis sa table ; l'organisateur rend le resultat final |
