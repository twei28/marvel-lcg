# Modular Sets (Skrull Menace Expansion) - transcription

Legend: "★" = black star printed before a rules line or Boost (the Boost star). "star icon" = red star symbol in the bottom-right corner (a boost "star" marker); "boost icon" = red Y-shaped icon. HP = orange number badge on minions. Card number = number printed bottom right after "MC Custom Content By: Kajislav". Duplicate copies were compared pixel-wise against the first copy (only the x/N label differs).
