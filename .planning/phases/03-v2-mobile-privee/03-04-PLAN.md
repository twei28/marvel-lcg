# Plan 03-04 — Plateau mobile V2

## Objectif

Polir le plateau mobile existant pour la V2 privée sans modifier le rendu V1 ni les parties invitées.

## Tâches

1. Activer le marqueur V2 avant le rendu React et charger une feuille dédiée.
2. Corriger les cibles tactiles, les zones sûres et les indices de défilement du plateau mobile.
3. Vérifier l'isolation V1/V2, le typage et le build de production.

## Critères de succès

- Les onglets joueur ont une cible d'au moins 44 px en V2.
- Le bandeau respecte les encoches et la préférence de réduction des animations.
- Toutes les règles sont strictement bornées à `data-ui-version="v2"`.
- Le typecheck et le build Vite passent.
