# Plan 03-02 — Préparation mobile V2

## Objective

Rendre le parcours de préparation nettement plus lisible au téléphone pour le
compte d'essai, sans modifier le DOM métier ni l'apparence V1.

## Tasks

1. Lire le cookie `ui_version` avant le rendu et exposer la version sur
   `documentElement.dataset`.
2. Ajouter une feuille V2 isolée qui simplifie l'accueil, agrandit les cibles,
   stabilise les barres et réserve leur espace dans le contenu.
3. Vérifier automatiquement l'isolation V1/V2, les cibles tactiles et les
   débordements aux largeurs 360, 390 et 480 px.

## Success Criteria

- Aucun sélecteur V2 ne s'applique sans le cookie.
- Les actions visibles font au moins 44 px.
- Aucune barre fixe ne recouvre le contenu.
- Aucun débordement horizontal aux trois largeurs de référence.
- La logique existante de préparation n'est pas modifiée.
