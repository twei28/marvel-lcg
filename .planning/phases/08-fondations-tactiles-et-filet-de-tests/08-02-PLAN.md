API exposée (contrat utilisé par les plans 08-04 à 08-10, ne pas renommer) : `window.marvelSaisie = { version: 1, CLES, classerAppareil, saisieInitiale, saisieApresGeste, estZoneLimite, normaliserTactile, normaliserPlateau, normaliserLimite, appareil(), saisie(), dernierGeste(), reglageTactile(), changerReglageTactile(v), reglagePlateau(), changerReglagePlateau(v), preferenceLimite(), changerPreferenceLimite(v), zoneLimite(), doitDemanderEcranLimite(), mesures(), installer(win) }`.
`CLES = { tactile: 'mc_ecran_tactile_v1', plateau: 'mc_plateau_v1', limite: 'mc_ecran_limite_v1' }`. Ancienne clé lue pour migration : `mode-plateau`.

Fonctions pures (cas à tester, table) :
- `classerAppareil({ platform, maxTouchPoints, pointeurFin, pointeurGrossier })` :
  `{MacIntel, 5, fin:true, grossier:false}` -> 'tactile' (iPad-Mac avec trackpad) ; `{MacIntel, 0, true, false}` -> 'pc' (vrai Mac) ; `{Win32, 10, true, false}` -> 'pc' (portable tactile, pointeur principal fin) ; `{Win32, 0, false, true}` -> 'tactile' (WebKit émulé : maxTouchPoints 0) ; `{Win32, 1, false, true}` -> 'tactile' (Chromium hasTouch) ; `{Win32, 0, true, false}` -> 'pc' ; `{Linux armv8l, 5, false, true}` -> 'tactile' ; `{'', 0, false, false}` -> 'pc'.
  Ordre : iPad-Mac (`platform === 'MacIntel' && maxTouchPoints > 1`) ; sinon pointeurFin -> 'pc' ; sinon pointeurGrossier ou maxTouchPoints > 0 -> 'tactile' ; sinon 'pc'. Commenter la lecture de `navigator.platform` comme exception assumée (seul repérage de l'iPad), seule du projet.
- `saisieInitiale(reglage, appareil)` : 'toujours' -> 'doigt' ; 'jamais' -> 'souris' ; 'auto' -> tactile ? 'doigt' : 'souris'.
- `saisieApresGeste(reglage, appareil, pointerType)` : réglage non auto -> valeur fixe ; appareil 'pc' -> 'souris' ; 'mouse' -> 'souris' ; 'touch' ou 'pen' -> 'doigt' ; type inconnu -> null (pas de changement).
- `estZoneLimite({ largeur, hauteur, appareil })` : vrai seulement si appareil 'tactile' ET 500 <= largeur <= 767 ET hauteur >= 500. Cas : 744x1133 tactile -> vrai ; 820x1180 -> faux ; 390x844 -> faux ; 480x1050 (gabarit s24) -> faux ; 507x768 -> vrai ; 667x375 -> faux ; 744x1133 pc -> faux ; 500x500 -> vrai ; 767x500 -> vrai ; 768x1024 -> faux.
- Normaliseurs : `normaliserTactile(x)` -> 'auto'|'toujours'|'jamais' (défaut 'auto') ; `normaliserPlateau(x)` -> 'auto'|'telephone'|'tablette' (défaut 'auto') ; `normaliserLimite(x)` -> 'telephone'|'tablette'|null.

Comportement avec état (testé en exécutant le VRAI fichier dans `node:vm` avec une fausse fenêtre : `document` et `window` construits sur `EventTarget` de Node, `documentElement.dataset` objet, `localStorage` en Map, `matchMedia` bouchonné, `setTimeout` réel ou contrôlé, `location.search`) :
- Au chargement : `data-appareil` posé ; `data-saisie` = `saisieInitiale(reglageTactile(), appareil)`.
- Adresse contenant `cadre` (cadre du spectateur et de la relecture) : `data-saisie="souris"`, aucun écouteur de geste, `doitDemanderEcranLimite()` faux.
- Geste : `pointerdown` (capture, sur document) mémorise le type candidat ; `pointerup`/`pointercancel` programment l'application au PREMIER de : `click` suivant (capture, puis `setTimeout(0)` pour laisser les gestionnaires du clic s'exécuter d'abord) ou délai de garde de 400 ms. Avant ce moment, l'attribut n'a PAS changé (cas testé : attribut lu juste après `pointerup` = ancienne valeur). Le `pointerType` du `click` n'est JAMAIS lu (WebKit y met 'mouse' après un toucher).
- `pointermove` de type 'mouse' sans bouton enfoncé (`buttons === 0`) : bascule en souris, sauf dans les 500 ms qui suivent un `pointerup` tactile (hystérésis : cas testé).
- Changement effectif de `data-saisie` -> `window.dispatchEvent(new CustomEvent('marvel:saisie', { detail: { saisie } }))` (dans le vm, fournir `CustomEvent` ou un repli `Event` + propriété `detail`).
- `changerReglageTactile(v)` : écrit la clé normalisée, réapplique `data-saisie` tout de suite (`saisieInitiale`), émet `marvel:saisie` si changement.
- `reglagePlateau()` : clé `mc_plateau_v1` si présente ; sinon migration en lecture seule : `mode-plateau === 'pc'` -> 'tablette', tout le reste -> 'auto' (rien n'est écrit). `changerReglagePlateau(v)` et `changerPreferenceLimite(v)` écrivent et émettent `marvel:plateau`.
- Écouteur `storage` : un changement de `mc_ecran_tactile_v1` dans un autre onglet réapplique ; `mc_plateau_v1`/`mc_ecran_limite_v1` réémettent `marvel:plateau`.
