**B. `scripts/comparer.mjs`**
Script Node ESM sans aucune dépendance. Il lit :
- les références dans `references/<ecran>/<gabarit>.png` ;
- les captures du dernier run dans `test-results/**` — Playwright y écrit `<nom>-actual.png` et `<nom>-diff.png` pour chaque test en échec. Repérer les fichiers par suffixe, pas par chemin exact (l'arborescence de `test-results` dépend du nom du test et du projet).

Il produit `comparaison/index.html` + un dossier `comparaison/images/` où il COPIE toutes les images utilisées, pour que la page soit consultable en `file://` sans dépendre de chemins fragiles.

Contenu de la page, entièrement en français, sans vocabulaire technique :
- un titre « Comparaison des écrans — avant / après » et la date/heure du run ;
- un mode d'emploi de 3 lignes en haut : ce qu'on regarde, quoi faire si tout va bien (« ferme cette page, il n'y a rien à valider »), quoi faire si un changement est voulu (« lance la commande `npm run captures:valider` dans le dossier ui-check et écris OUI ») ;
- une section par écran (titre FR issu de `ecrans.ts`), et dans chaque section une ligne par gabarit (Ordinateur / Tablette / Téléphone) ;
- pour un couple SANS différence : l'image de référence + un badge vert « Aucun changement » ;
- pour un couple AVEC différence : trois images côte à côte légendées « Avant (référence) », « Après (nouvelle capture) », « Ce qui a changé », plus un curseur (`<input type="range">`) qui superpose avant/après en faisant varier l'opacité de l'image du dessus. CSS et JS inline, aucune ressource externe.
- un compteur en tête : « X écrans sur 18 ont changé ».
Le script termine en affichant en français le chemin absolu de la page et la commande pour l'ouvrir.

`comparer.mjs` ne doit JAMAIS écrire dans `references/`.
  </action>

<task type="auto">
  <name>Tâche 2 : Validation explicite des nouvelles références</name>
  <files>ui-check/scripts/valider.mjs</files>
  <action>
Script Node ESM interactif, tout en français, sans dépendance (`node:readline/promises`).

Déroulé :
1. Refuser tout de suite si `comparaison/index.html` n'existe pas : « Il n'y a rien à valider : lance d'abord `npm run captures:comparer` et regarde la page de comparaison. » (code de sortie 1).
2. Refuser si `comparaison/index.html` est plus vieux que le dernier fichier de `test-results/` : « La page de comparaison n'est pas à jour. Relance `npm run captures:comparer`. » (code de sortie 1).
3. Afficher la liste des écrans qui vont changer de référence (déduite des `-actual.png` présents dans `test-results/`), avec leurs titres français.
4. Poser exactement : « Tu as bien regardé la page de comparaison et tous ces changements sont voulus ? Écris OUI en majuscules pour figer les nouvelles images comme référence. Toute autre réponse annule. »
5. Si la saisie n'est pas exactement `OUI` : afficher « Annulé — aucune référence n'a été modifiée. » et sortir en 0.
6. Si `OUI` : lancer `npx playwright test tests/captures.spec.ts --update-snapshots=changed`, puis relancer `npx playwright test tests/captures.spec.ts` pour prouver que c'est vert, puis afficher « C'est figé. Les nouvelles images sont maintenant la référence. »
7. Le script REFUSE de tourner si `UI_CHECK_DEMO` est défini dans l'environnement : « Le mode démonstration est actif, on ne fige pas une différence factice. » (code de sortie 1). C'est le garde-fou qui empêche de valider la démo par accident.

Ne prévoir AUCUN drapeau non interactif (`--yes`, `--force`) : la confirmation manuelle est la fonctionnalité.
  </action>
  <verify>
```bash
cd "/mnt/c/Users/arnau/Desktop/Marvel LCG last try/ui-check"
# Empreinte des références avant
find references -name '*.png' -exec sha256sum {} \; | sort > /tmp/refs_avant.txt
# Chemin du refus : toute réponse autre que OUI ne doit RIEN changer
UI_CHECK_DEMO=1 npm run captures:comparer || true

diff /tmp/refs_avant.txt /tmp/refs_apres.txt && echo "REFUS OK : references intactes"
# Garde-fou mode démo : même en répondant OUI, le script doit refuser
printf 'OUI\n' | UI_CHECK_DEMO=1 npm run captures:valider ; echo "code=$?"   # attendu : refus, code 1
find references -name '*.png' -exec sha256sum {} \; | sort | diff - /tmp/refs_avant.txt && echo "GARDE-FOU DEMO OK"
npm run captures   # retour au vert, exit 0
```
  </verify>
  <done>Répondre autre chose que `OUI` laisse les 18 empreintes de référence identiques. Répondre `OUI` alors que `UI_CHECK_DEMO` est actif est refusé. Aucun drapeau ne permet de contourner la question.</done>
