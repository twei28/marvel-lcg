**A. `ui-app/aspects.js`** : module ES en JavaScript pur (pas de TypeScript) car le meme fichier est servi tel quel aux pages anciennes. Il est la source unique ; `deployer.sh` en depose une copie dans `public/js/aspects.js`, exactement comme `tokens.css`. Format `.js` obligatoire : `.json` n'est pas dans la liste blanche du serveur (200 avec une image JPEG), convention deja actee en phase 1 pour les fixtures.

```js
// Source unique des aspects. Copiee vers public/js/aspects.js par deployer.sh.
// Regle ACC-01 : un aspect ne s'affiche JAMAIS par la seule couleur.
// La forme autorisee est toujours : icone + libelle (+ couleur en renfort).
export const ASPECTS = {
  aggression: { libelle: 'Agression',    token: '--mc-aspect-agression',    svg: '<svg ...>' },
  justice:    { libelle: 'Justice',      token: '--mc-aspect-justice',      svg: '<svg ...>' },
  leadership: { libelle: 'Commandement', token: '--mc-aspect-commandement', svg: '<svg ...>' },
  protection: { libelle: 'Protection',   token: '--mc-aspect-protection',   svg: '<svg ...>' },
  basic:      { libelle: 'Base',         token: '--mc-aspect-base',         svg: '<svg ...>' },
  pool:       { libelle: 'Pool',         token: '--mc-aspect-pool',         svg: '<svg ...>' },
};
```

Les icones sont a CREER : aucun glyphe d'aspect n'existe dans les polices du jeu. Contraintes :
- SVG en ligne dans le module, jamais des fichiers `.svg` : la route `.svg` du serveur ne lit que `assets/textures/` a plat, un `.svg` sortant du build tombe en 404.
- `viewBox="0 0 24 24"`, `fill="currentColor"`, aucune taille en dur, aucun `id` (le meme SVG sera insere plusieurs fois dans une page).
- Formes franchement differentes les unes des autres, reconnaissables en niveaux de gris et a 16 px : par exemple poing pour Agression, balance pour Justice, etoile pour Commandement, bouclier pour Protection, cercle plein pour Base, losange pour Pool. Une silhouette simple vaut mieux qu'un dessin detaille.
- Aucun `title` a l'interieur : le libelle est du texte dans le DOM, pas une infobulle.
